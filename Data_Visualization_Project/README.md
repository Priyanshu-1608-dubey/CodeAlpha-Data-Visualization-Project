# 📊 Data Visualization & EDA Project

## 🧠 Project Overview

This project is based on **Exploratory Data Analysis (EDA)** and **Data Visualization** using a real-world dataset from **Kaggle**.  
The main objective is to analyze the dataset, clean the data, and extract meaningful insights using visual techniques.

This project is created as part of a **task provided by a company (PDF-based task)** and showcases practical data analytics skills.

---

## 🎯 Objectives

- Load and understand the dataset
- Clean and preprocess data
- Perform Exploratory Data Analysis (EDA)
- Visualize insights using charts and graphs
- Create dashboard outputs for better understanding
